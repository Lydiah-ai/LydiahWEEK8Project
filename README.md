# LydiahWEEK8Project
Library Management System
Manage books, authors, members, and borrowing records. The Database has the following tables
	Authors Table
	Books Table
	Members Table
	Borrowing Records Table
Relationships
One-to-Many: Authors to Books (one author can write many books)
Many-to-Many: Members to Books via BorrowingRecords (many members can borrow many books)
